# RangManch-Space
Description : CloudColors Dashboard

![image alt](https://github.com/Pooja-Vartia/RangManch-Space/blob/main/colorCloudUpdate1.png?raw=true)

  A creative playground and responsive dashboard for testing color contrast and accessibility with blindness mode previews and text       formatting tools.
- Test color contrast ratios for accessibility compliance.
- Preview text in different **color blindness modes**.
- Format text with a responsive toolbar (bold, italic, underline, caps, alignment).
- Apply background/foreground colors, gradients, and random palettes.
- Save and reuse custom palettes.

## ✨ Key Features

![image alt](https://github.com/Pooja-Vartia/RangManch-Space/blob/94ad446da9eed7d7179b920e217c756f5bbbe40f/keyfeatureofColorContrast.JPG)

### 🎨 Test Color Contrast
Check color contrast ratios to help ensure accessibility compliance and improve text readability.

### 👁️ Color Blindness Preview
Preview your designs in different color blindness modes to create more inclusive visual experiences.

### 🔤 Text Formatting Toolbar
Format text using bold, italic, underline, and other alignment options for better presentation.

### 🎨 Background & Gradients
Apply solid colors, gradients, and random palettes to explore creative color combinations.

### 💾 Save Custom Palettes
Save and reuse your favorite color palettes for consistent and efficient design workflows.

## 🛠️ Technologies Used

CloudColors Dashboard is built using a combination of web technologies that work together to create an interactive, responsive, and user-friendly experience.

### 🌐 HTML5
Used to structure the web pages and organize the content of the dashboard.

### 🎨 CSS3
Used to style the interface, create attractive layouts, apply colors and gradients, and ensure responsive design.

### ⚡ JavaScript
Adds interactivity and powers features such as color contrast testing, color blindness previews, text formatting, and custom color palettes.

### 🐘 PHP
Used for server-side scripting and handling backend functionality where required.

### 🗄️ MySQL
Used for database management and storing user-related data or saved preferences where implemented.

![image alt](https://github.com/Pooja-Vartia/RangManch-Space/blob/56ead892007a1858095b020bb476d2dbcbea37ce/technolyColorContrast.JPG)


These technologies combine to make CloudColors Dashboard a creative and accessible platform for exploring colors and designing better digital experiences.
